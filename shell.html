File Handling in WASM

Emscripten provides a virtual MEMFS in the browser. fopen/fprintf/fscanf work normally. Data persists until page reload.

Input Method

Uses setbuf(stdout,NULL) + Emscripten's ASYNCIFY flag for synchronous scanf-style blocking input in the browser.
